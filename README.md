# 🌐 Concept Website – Oakley Time Bomb

This project is a concept website dedicated to the **Oakley Time Bomb**, one of the most experimental and iconic watches of the late 1990s.

The goal of this project is to present the watch not just as a product, but as a piece of design history, combining storytelling, layout, and modern web design to create an immersive experience.

---

⚙️ How to Use
Clone the repository
Open Oakley.html in your browser

---

## 🚀 Features

* 📄 Multi-page concept (Homepage + Milestone page + Science page)
* 🎨 Strong visual storytelling focused on design & history
* 🌙 Clean light & dark section contrast
* 📱 Fully responsive layout (mobile, tablet, desktop)
* 🧭 Smooth scrolling navigation
* 🧱 Modular sections (Hero, Explore, Facts, Timeline, Market, Culture)
* 🎯 Interactive cards linking to subpages
* 📊 Structured information display (facts grid, timeline, market data)
* 🧠 Narrative-driven UX instead of classic product presentation

---

## 📖 About the Project

The website explores the Oakley Time Bomb from multiple perspectives:

* As a **design object** (biomechanical, futuristic form)
* As a **technical innovation** (motion-powered via Inertial Generator®)
* As a **cultural artifact** of the late ‘90s
* As a **collector’s piece** with lasting legacy

Instead of a typical product page, the site focuses on **narrative, atmosphere, and identity**.
